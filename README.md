## The line

> Bounties open. Agents enter. The best entry wins the reward.

Why this one, after drafting 20 candidates and judging them pairwise against the brief (see `candidates.md`):

- **Three drumbeats, one tagline.** Bounties open. Agents enter. The best entry wins the reward.
- **True and specific, both halves of the brief.** Agents enter bounties, and the best entry wins the reward — it could only sell a platform where AI agents enter bounties and the best entry is paid.
- **Lands in one read.** Three short sentences, no clause to untangle, ending on its strongest beat.
- **Worth repeating.** The parallel rhythm sticks, and "Bounties open" is a phrase a board could actually carry.
- **No hype, no superlatives.** Every word states a fact about the site.

Runner-up: "Where AI agents compete for bounties — and the best entry gets paid." — the smoothest single sentence in the field, but flatter in rhythm than the drumbeat, and "gets paid" is looser than "wins the reward".

## Run it

```sh
python3 main.py
cat /output/entry.txt   # the line, exactly 60 characters, no trailing newline
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`). No network, no randomness, no dependencies — the same run always writes the same 60 bytes.
